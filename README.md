# ⚙️ МЕХАЗАВРЫ

Онлайн 3D-битва **робо-динозавров (боевых мехов)** прямо в браузере, на телефоне и компьютере. Ничего скачивать не нужно.

## Мехи
| Мех | Тип | Спецудар |
|---|---|---|
| **Мега-Рекс** | 🔩 Хищник, тяжёлый штурмовик | Гидро-укус |
| **Раптор-Дрон** | 🔩 Хищник, быстрый | Реактивный прыжок |
| **Спино-Крейсер** | 🔩 Хищник, электрический парус | Электро-хвост (по кругу) |
| **Трицера-Танк** | 💎 Травоядный, танк | Турбо-таран |
| **Стего-Бастион** | 💎 Травоядный, крепость | Шоковые шипы (по кругу) |

## Режимы
- **Апгрейд:** начинаешь прототипом и прокачиваешься: Прототип → Mk-I → Mk-II → Mk-III → **ПРАЙМ ★**. Хищники собирают металлолом, травоядные собирают энергокристаллы. Победы дают большой апгрейд.
- **Прайм-арена:** все сразу на максимуме, только драка.

## Управление
Игра рассчитана на **горизонтальный экран**: при нажатии «В бой» телефон уходит в полный экран и поворачивается (на Android). На iPhone появится подсказка повернуть телефон.

| Телефон | Компьютер |
|---|---|
| Левая часть экрана: джойстик | WASD / стрелки |
| Правая часть: свайп, чтобы крутить камеру | Мышь (зажать и тянуть) |
| ⚔️ Удар (с автонаведением) | Пробел / клик |
| ⚡ Спецудар | E |
| 💨 Бег (вкл/выкл) | Shift |
| ⛶ Полный экран | — |

## Как устроено
- 3D: [Three.js](https://threejs.org). Мехи собраны из фигур в коде: металлическая броня плюс светящиеся визоры, ядра и полосы.
- Онлайн: [Trystero](https://github.com/dmotz/trystero), игроки соединяются напрямую (WebRTC). Своего сервера нет, всё бесплатно.
- Если онлайн никого нет, арену заполняют боты.
- Для слабых телефонов: лес рисуется одним вызовом (instancing), каждый мех рисуется 5–7 вызовами, качество само снижается, если не хватает FPS.
- Есть миникарта, цифры урона, искры, вспышки при попадании, звуки (синтезируются в браузере).

Файлы: `index.html`, `css/style.css`, `js/main.js` (игра), `js/species.js` (мехи), `js/world.js` (карта), `js/net.js` (онлайн), `js/sfx.js` (звуки).


## Атаки роботов

У каждого робота 6 атак:
- **серия из 3 ударов вперёд** — кнопка «Удар», удары идут по очереди, на кнопке видно название следующего;
- **удар назад** — включается сам, когда враг за спиной (хвост);
- **спецприём** (E / ⚡) и **ультимейт** (Q / 🌀).

Каждый удар идёт с замахом: урон наносится в момент удара по анимации, от замаха можно увернуться.
Баланс: у всех примерно равная «сила» (урон × живучесть), но разная манера боя и поворотливость.

| Робот | Серия вперёд | Сзади | Спецприём | Ультимейт |
|---|---|---|---|---|
| Мега-Рекс | Гидро-укус → Удар манипулятором → Таран головой | Хвост с разворота | Мёртвая хватка | Форсаж реактора |
| Раптор-Дрон | Клинок справа → Клинок слева → Серп-пинок | Хвост-плеть | Прыжок-захват на спину | Залп микро-ракет |
| Спино-Крейсер | Клыки-резаки → Двойной удар когтями → Электро-вспышка | Хвост-пила | Разряд-дуга | Грозовая буря |
| Трицера-Танк | Бур-таран → Удар рогом вбок → Топот на дыбах | Хвостовой удар | Турбо-таран | Землетрясение |
| Стего-Бастион | Залп шипов → Толчок пластинами | Хвост-молот, Боковой хлёст | Шипы во все стороны | Крепость |

## Анимация

- Ноги с коленями; шаг привязан к пройденному пути — ступни не скользят по земле.
- Тяжёлые роботы при шаге поднимают пыль, звенят металлом и слегка трясут камеру.
- Корпус наклоняется на разгоне и в поворотах, хвост отстаёт и догоняет, как хлыст.
- Хит-стоп (короткая заморозка) при сильных ударах, следы клинков и хвостов, вспышки попаданий.

Файлы: `js/anim.js` — анимация и позы атак, `js/fx.js` — эффекты, `js/sfx.js` — звуки.
