# 🦖 Dino Арена

Онлайн 3D-игра про динозавров прямо в браузере, на телефоне и компьютере. Ничего скачивать не нужно.

## Как играть
- Выбери одного из 5 динозавров: **Тираннозавр, Велоцираптор, Спинозавр, Трицератопс, Стегозавр**.
- **Рост:** начинаешь детёнышем и растёшь (Детёныш → Подросток → Молодой → Взрослый → **Прайм ★**). Рост идёт сам, а еда и победы его ускоряют. До прайма примерно 1–2 минуты.
- **Прайм-арена:** все появляются сразу праймами, только драка.
- Хищники едят мясо (туши), травоядные едят ягодные кусты. Еда лечит.

### Управление
| Телефон | Компьютер |
|---|---|
| Левая половина экрана: джойстик | WASD / стрелки |
| Правая половина: свайп для поворота камеры | Мышь (зажать и тянуть) |
| 🦷 Атака | Пробел / клик |
| ✨ Спецудар | E |
| 💨 Бег (вкл/выкл) | Shift |

## Как устроено
- 3D: [Three.js](https://threejs.org), низкополигональные модели собраны из фигур в коде, без файлов моделей.
- Онлайн: [Trystero](https://github.com/dmotz/trystero), игроки соединяются напрямую (WebRTC). Свой сервер не нужен, всё бесплатно.
- Если никого нет онлайн, арену заполняют боты (ими управляет первый зашедший игрок).
- Оптимизация: деревья рисуются одним вызовом (instancing), тени без затрат, качество само снижается, если телефон не тянет.

Файлы: `index.html`, `css/style.css`, `js/main.js` (игра), `js/species.js` (динозавры), `js/world.js` (карта), `js/net.js` (онлайн), `js/sfx.js` (звуки).
